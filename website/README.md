# MeetOrbit static site

Serve this folder as static HTML. No build step or Node web service is needed. `index.html` is the entry point, `screens.html` is the device gallery, and all assets are local. No API credentials are needed to view the site.

For DigitalOcean App Platform, deploy repository `sfandetti/meetorbit`, branch `main`, source directory `/website`, component type **Static Site**, output directory `.`. Do not run the companion's npm start command to host this site. Hosting and DNS are separate from the open-source repository publication.
