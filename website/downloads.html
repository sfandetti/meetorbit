Hardware / Prototype design files

Capsule v1
enclosure files.

Orbit is a working prototype, and it is fun to use. We intend to optimize it, make it smaller, develop a dedicated circuit board to simplify assembly, and offer an assembled version for sale. The smaller hardware and custom board are still in development; there is no finished production version available yet.

The Capsule v1 enclosure set includes individual STL models and numbered 3MF print plates, plus fit-test pieces and alternate parts.

These are the actual project files, packaged with a revision note so the variants stay identifiable. They are prototype resources, not final production manufacturing files.

Software. Firmware. Hardware.

Modify the software.
Build your own version.

The open-source repository includes the Windows companion, device firmware and Capsule hardware resources. We encourage new integrations, alternate interfaces, enclosure changes and independent versions of Orbit.

The public GitHub repository contains the companion software, firmware, Capsule enclosure files, build guides and website. Fork it, report issues or contribute an integration. Software is MIT licensed; original hardware uses CERN-OHL-P-2.0. The device shown is the first prototype; a smaller, portable revision is in development for the intended assembled product, with release dependent on production readiness.
