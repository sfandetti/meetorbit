02 / File deletion & session controlsExplicit targets. Review before deletion.

Delete selected files.
Clear local browser data.

Configure cleanup targets on your PC, then trigger the workflow from Orbit or the console.

Folder cleanup

  • Select up to 12 specific local folders.
  • Delete their contents; keep the folders themselves.
  • Review file count, total size and target paths before confirming.
  • System paths, whole top-level personal folders, network shares and linked targets are blocked.

Browser cleanup

  • Chrome, Edge and Brave.
  • Choose history, cookies and cache independently.
  • Applies to standard local browser profiles; bookmarks stay.
  • Browsers must be closed. Clearing cookies signs you out.

Session controls

  • Lock Windows or request sign-out.
  • Optional 4–6 digit device passcode.
  • PC commands and cleanup require the configured passcode.
  • Cleanup uses a review and confirmation flow, with a final check that targets have not changed.

Deletion scope: local files and selected browser data. Sync, backups and cloud copies are outside this cleanup. It deletes files; it does not promise forensic erasure on SSDs.

Host telemetry

The readings, not a score.

Processor & memory

  • CPU utilisation
  • RAM used and total RAM
  • GPU utilisation and VRAM
  • Temperature where the driver exposes it

Storage & network

  • Drive used / free space
  • Disk busy percentage
  • Read and write throughput
  • Network download and upload rates

Collection

  • Host collection loop: approximately 1 second
  • NVIDIA: nvidia-smi
  • AMD / Intel: Windows WDDM data
  • Unavailable fans, watts or sensors stay unavailable

Local controls

Media keys.
Scripts. AI Sentry.

Use Windows media controls, adjust master volume and configure six app or command shortcuts. Executables can have arguments and a working folder; scripts can run with or without a command window.

Sentry can capture snapshots, preview a camera, record locally and save motion-triggered clips. Clips include a short lead-in and five seconds after movement, up to 60 seconds per clip. Recording stops at the selected storage limit; it does not silently delete old clips.

Party tricks / Philips Hue

Room controls. Music Link. Visuals.

Pair a compatible Hue bridge in the companion. Control rooms and brightness, choose a mood, or let Music Link react to the visualizer’s beat and audio levels. Stop the mode to restore remembered settings.

Effects depend on the connected lights. White lights follow compatible brightness/white-tone controls. Hue hardware is not included with Orbit.

Implementation & release status

Current build status.

Device firmware

AI voice, PC readings, media controls, LED effects, Wi-Fi pairing, compatible OTA updates and the Codex console are in the working device prototype. Codex needs a conversation paired on the host PC.

Prototype

Windows source

The current Node source includes all four AI desk providers, voice, lights, Codex, Sentry, shortcuts and privacy cleanup. Screenshots show this current development console. End-to-end testing and installer packaging are part of release preparation.

Development

Public release

The source is public on GitHub. Matched installer / firmware downloads are still being prepared and validated. The next hardware revision is a smaller, portable design and the intended production version. Release timing depends on readiness to produce it.
